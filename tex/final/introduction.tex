In machine learning, there exists a large number of algorithms, notably neural networks trained with gradient descent, which achieve great performances at prediction tasks on unseen data. A big question in learning theory is to understand the relationship between the behavior of such algorithms on the available data and their future behavior on unseen data (generalization). How can we predict how this future behavior will look like? 

A number of results have tried to answer this question~\cite{boucheron2005theory,bartlett2002rademacher,vapnik2013nature, jiang2019fantastic}. Recent works seem to suggest that the classical theory fails to explain generalization, in particular they fail to describe the behavior of the test error of learning algorithms as the comlpexity of the hypotheses set increases~\cite{belkin2019reconciling,zhang2016understanding,zhang2021understanding, nagarajan2019uniform}.

This thesis seeks to understand whether this is true by testing theoretical results against empirical evidences. We study the setting of a finite hypotheses set of binary decision trees. We look for a bound on the test error as the maximum depth of the decision trees (i.e.\ the complexity of the hypotheses space). In particular, we want this function to qualitatively reproduce the test error curve as well as to be sensitive to changes in the structure of the learning problem that influence the generalization performance of the algorithm. We test a number of candidates coming from existing theoretical results against empirical evidence to analyze their validity.
